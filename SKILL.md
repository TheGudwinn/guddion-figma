# Guddion Figma — как пользоваться инструментами

Короткая шпаргалка для агента: в каком порядке звать инструменты, чтобы не тратить токены впустую и не упираться в rate limit Figma.

## Чтение (REST, Figma Desktop не нужен)

1. **`resolve_link`** — всегда первый шаг, если у тебя есть ссылка пользователя. Превращает её в `fileKey` + `nodeId`.
2. **`get_metadata`** — осмотрись в структуре фрейма, прежде чем тащить всё целиком. Возвращает только id/name/type/bounds, дёшево по токенам даже на больших фреймах.
3. **`get_node_tree`** с `maxDepth` — точечно загружай полную детализацию (fills, strokes, текст, стили) только для той ветки, которая реально нужна. Не вызывай без `maxDepth` на фреймах с глубокой вложенностью — ответ может быть огромным.
4. **`get_styles`** / **`get_components`** — метаданные файла, если нужно сопоставить id стиля/компонента с именем.
5. **`export_image`** — рендер в картинку; можно сразу несколько `nodeIds` за один вызов, и с `outputDir` — прямо на диск, без возни со ссылками.

## Design tokens

- **`get_variables`** (plugin) — локальные variables и коллекции.
- **`export_tokens`** (plugin) — то же самое, но сразу в виде DTCG JSON и CSS custom properties. Используй это, а не ручной парсинг `get_variables`, если цель — подключить токены к коду.
- **`set_variable`** (plugin) — изменить значение переменной для конкретного mode.

## Запись (plugin, нужен открытый файл + запущенный плагин)

- Перед любой записью — `get_plugin_status`, чтобы убедиться, что плагин подключён и это тот файл.
- **`find_node`** — ищи ноду по имени/типу вместо того, чтобы просить пользователя копировать ссылку на каждый элемент.
- **`write_node`** — создать FRAME/RECTANGLE/TEXT.
- **`update_node`** — поправить существующую ноду (позиция, размер, fills, текст, видимость).
- **`clone_node`** / **`move_node`** — размножить или переместить между родителями.
- **`delete_node`** — удалить.

## Диагностика

- **`whoami`** — если REST-инструменты падают с ошибкой авторизации, сначала проверь этим, валиден ли токен.
- **`rate_limit_status`** — сколько запросов ушло за последнюю минуту, если подозреваешь, что упираешься в лимит.

## Общее правило

REST — для чтения по ссылке, разово, без Figma Desktop. Plugin Bridge — для записи и variables, требует открытого файла и запущенного плагина. Не переключайся на plugin-инструменты только ради чтения — для этого достаточно REST.
